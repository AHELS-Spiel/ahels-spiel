# de vorgehensweise

jeder macht sich seinen eigenen ordner im ideen ordner und schreibt da erstmal alle ideen für des spiel auf die ihm einfallen

später könn ma uns zusammenhocken und alle ideen besprechen was passt und was nicht


### aber wichtig:

- des spiel soll wie smash bros sein, also nix zu unpassendes
- immer schon an wagner haten


## wie mach ich des?

terminal aufmachen in dem ordner wo du des projekt haben willst
```sh
git clone https://github.com/jonasgoetzner/ahels-spiel.git
```
den eigenen ordner erstellen und ideen reinschreiben
```sh
git add --all
git commit -m "hier reinschreiben was du gemacht hast"
git push
```
